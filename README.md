# 📝 To-Do List Application

A modern and responsive task management web application built using HTML, CSS, and JavaScript. This application allows users to efficiently manage daily tasks with features like adding, deleting, completing tasks, and persistent local storage support.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑 Delete tasks
- 💾 Data persistence using Local Storage
- 📱 Responsive modern UI
- ⚡ Real-time DOM updates

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
